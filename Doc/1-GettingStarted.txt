# What is "Everchanging book of names"
Everchanging Book of Names

In role-playing games, authentic atmosphere is a sum of many things. Regional customs, garments, architecture and names are all among things that add to a fullfilling gaming experience. Unfortunately, more often than not, every person the player characters encounter in a fantasy game has its name lifted from a popular novel, or, even worse, the calendar.

Everchanging Book of Names (a.k.a. EBoN) is a shareware random name generator for 32-bit Microsoft Windows systems. Originally written to be a game master aid, it has since proven its usefulness in various situations other than role-playing, such as naming fabrics, cats and miniature horses. Its highly sophisticated algorithm ensures that most of the names generated by it are readily usable. Moreover, the wide selection of name sets (called chapters) ensure that the names are truly unique and come in different flavors.

The software is written and copyright © 1997-2002 by Sami Pyörre. Its latest version, along with an ever-increasing number of additional chapters, can always be downloaded from the official EBoN page:

http://ebon.uni.cc 

# Whats in version 3.4

Revision 3.4

Added support for book info in Help files.
Fixed a bug in registration checking on Windows 2000 and XP.
Fixed a bug that froze the program on single-element names.
Fixed a bug that froze the program on some initial letters.

Revision 3.3
Added support for handling names with whitespace characters.
Implemented smarter registration checking.
Changed default window position and rearranged some buttons.
Fixed a bug that caused problems with finding books.
An empty TEMPLATES tag no longer crashes the software.

Revision 3.2

Fixed a color problem with Windows NT and Windows 2000.
Added automatic appending of default file extensions.

Revision 3.1
Added plain text format (.txt) for saving files.
Fixed a problem with unusual color schemes.
Fixed incorrectly working Prefix and Suffix checkboxes.

Version 3.0
Source code was imported to Borland C++ Builder 3.

Unlimited history can be browsed in the program dialog.
Names can be selectively saved into different files.
Additional information can be saved with the names.

Visual interface was enhanced.
This help file was rewritten.

Maximum number of names is no longer limited.
Chapters can be bound into books.
Help file topics can be associated with chapters.
Complex names can be generated using templates.
Chapters can be distributed in quick chapter format.

Version 2.x chapters are compatible with this version.
Version 1.0 chapters are no longer supported.
